# Deep Elements - Answer Key

For teachers. Every quiz question in the game, with its answer and the other pads on
offer. This file is written by `generate-answer-key.js` from the level files, so it
always matches the game; it is not shown inside the game.

In the game the answers are dealt onto the pads afresh every time a level loads, so
the key gives the element, not a pad position. A wrong pad costs thirty seconds.

## Element Runs

A run has several doors. Each asks about the elements of the hall the player has just
crossed, and opens only its own door.
